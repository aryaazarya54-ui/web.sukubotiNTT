# WEBSITE SUKU BOTI NTT — VERSI LENGKAP

Website statis untuk GitHub Pages.

## Fitur
- Desain responsif HP/laptop.
- Hero foto Boti.
- Tentang lokasi dan identitas Boti.
- Halaika: Uis Neno dan Uis Pah.
- Arsitektur: ume kbubu, lopo, sonaf.
- Tenun: mau/beti, ttais, motif dan alur proses.
- Kehidupan: pertanian, peternakan, air, kebersamaan.
- Boti Dalam dan Boti Luar.
- Galeri foto.
- Sumber dan kredit foto.
- Link Google Maps.

## PENTING TENTANG FOTO
Beberapa foto Boti ditampilkan dari Wikimedia Commons melalui URL publik karena runtime ini tidak memiliki akses internet untuk mengunduh file gambar ke ZIP.
Foto Wikimedia yang dipakai memiliki halaman sumber/lisensi di Wikimedia Commons. Foto TelusuRI diberi keterangan bahwa izin/hak cipta harus diperiksa sebelum redistribusi.

Jika ingin website benar-benar mandiri/offline (semua JPG berada di folder assets), download foto yang lisensinya mengizinkan penggunaan, masukkan ke assets/, lalu ubah src gambar menjadi assets/nama-file.jpg.

## Hosting GitHub Pages
1. Buat repository baru.
2. Upload index.html, style.css, script.js, README.md.
3. Settings -> Pages.
4. Deploy from a branch.
5. Branch main + /(root).
6. Save.
